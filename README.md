# Automatic File Organizer

A beginner Python automation project that organizes files into folders based on their file extensions.

## Features

* Creates folders for images, documents, music, and videos.
* Uses Python's `os` and `shutil` modules.
* Moves recognized file types into the appropriate folders.
* Skips folders and leaves unsupported file types unchanged.

## Requirements

* Python 3
* No external packages required

## How to Run

1. Download or clone this repository.

2. Open a terminal in the project folder.

3. Run:

   `python file_organizer.py`

4. Enter the path to the folder you want to organize.

**Safety note:** Test with sample files first because the script moves files from their original locations.

## Project Status

Beginner learning project. Built to practice Python file handling and automation.
